# Games

A collection of simple games.

## List

### Minesweeper

The usual minesweeper game, with a timer and customizable sizes and mines.

### Sudoku

A common logic game.

### Tic Tac Toe

A ancient simple game of Xs and Os.

A very popular game first introduced on the Nokia.
